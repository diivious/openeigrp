# RFC 7868 reference

Copyright (C) 2026 Donnie V. Savage

RFC 7868 (*Cisco's Enhanced Interior Gateway Routing Protocol (EIGRP)*,
Informational, May 2016) is available from the
[RFC Editor](https://www.rfc-editor.org/rfc/rfc7868.html).

RFC 7868 is an important protocol reference, **not** the highest authority
for wire-format compatibility when it conflicts with verified Cisco captures.
See [Cisco/RFC errata and evidence rules](../eigrp/specs/cisco-errata.md),
which is the core-owned specification for confirmed differences and decisions.

Core implementation documents: [DUAL](../eigrp/specs/dual.md),
[route selection](../eigrp/specs/route-selection.md) and
[RTP](../eigrp/specs/rtp.md). Repository ownership is described in
[architecture](architecture.md).
